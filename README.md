# 🚗 Car Price Prediction System

## 📌 Project Overview
- **Subject:** AI Applications
- **Problem Type:** Regression
- **Dataset:** Kaggle – Used Car Dataset
- **Objective:** Predict the resale price of used cars.
- **Input Features:** Brand, Mileage, Engine Type, Age of Vehicle
- **ML Techniques:** Linear Regression, Random Forest Regressor
- **Evaluation Metrics:** Mean Absolute Error (MAE), Root Mean Squared Error (RMSE)
- **Outcome:** Helps buyers and sellers estimate fair car prices.
